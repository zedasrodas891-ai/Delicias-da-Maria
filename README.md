# 🥐 Delícias da Maria - Cardápio Digital

> Um cardápio digital interativo e elegante desenvolvido para uma confeitaria e padaria artesanal, facilitando a escolha de produtos e o envio direto de pedidos via WhatsApp.

## ✨ Funcionalidades

- **Navegação por Categorias:** Filtro rápido entre "Cardápio Completo", "Salgados e Pães" e "Doces e Biscoitos".
- **Opções Personalizadas:** Seleção de sabores e tamanhos para produtos específicos (ex: pães recheados).
- **Carrinho Flutuante Dinâmico:** Atualização em tempo real da quantidade de itens e valor total do pedido.
- **Forma de Recebimento:** Escolha flexível entre "Entrega em Endereço" ou "Retirada no Local" (com endereço automático da loja).
- **Persistência de Dados:** Memoriza o nome e preferências do cliente no `localStorage` para facilitar compras futuras.
- **Integração com WhatsApp:** Geração automática e formatada da mensagem de pedido pronta para ser enviada diretamente ao estabelecimento.

- **Modal de Imagens:** Visualização ampliada das fotos dos produtos ao clicar neles.

🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias web fundamentais, sem dependência de frameworks complexos, garantindo alta performance e leveza:

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização moderna com variáveis (`:root`), flexbox, grid layouts, efeitos de vidro (`backdrop-filter`) e design totalmente responsivo.
- **JavaScript (ES6+):** Lógica do carrinho de compras, manipulação dinâmica do DOM, sistema de abas e integração com a API do WhatsApp.
- **FontAwesome:** Ícones vetoriais para uma interface mais intuitiva.
- **Google Fonts:** Tipografia utilizando a fonte *Poppins*.
